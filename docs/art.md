# 美术规范

本文档规定画面看起来应该是什么样：风格、色彩、光照、2D 人物、势力风格、UI、特效和后处理。模型怎么做、怎么导出见 `docs/modeling.md`。

标注：**已定**是制作人确认过的；**建议**是 AI 提出、还没有确认的，可以先按它做，但不能当成定论；**待定**必须由制作人决定后才能做正式素材。

---

## 1. 风格定位（已定）

- **风格名称**：风格化手绘 PBR（Stylized Painterly PBR）。
- **参考方向**：《漫漫长夜》《看火人》《双城之战》室内场景的笔触质感。
- **三条原则**：
  1. **克制与留白**：延续原版"少给信息、逐步揭示"。不堆高饱和度特效和花哨 UI，让光影和物件本身承担叙事。
  2. **手绘触感 × 真实光影**：剪影和表面保留水粉、油画的大笔触；光照、阴影、体积氛围走真实物理逻辑，突出冷暖对比。
  3. **光即信息**：光源必须来自场景里看得见的实体（火堆、火把、提灯、门缝的天光）。光照范围和强度直接映射模拟层的状态。

路线图里"低分辨率渲染 + 调色板量化 + 抖动"的方案已被本风格替代，不再使用。

## 3. 色彩（已定）

整体是**低饱和暖棕 × 灰蓝/橄榄绿**的对比基调，让暖橙色的火光成为画面的绝对焦点。

| 区域 / 材质 | 色调 | 参考色（线性空间） | 说明 |
| --- | --- | --- | --- |
| 上部抹灰墙 | 暖米黄 / 赭灰 | `(0.34, 0.24, 0.17)` → `(0.60, 0.47, 0.35)` | 大笔触扫刷，局部剥落露出红砖 |
| 下部墙裙 | 灰蓝绿 / 黛青 | `(0.075, 0.135, 0.135)` → `(0.19, 0.28, 0.26)` | 世界坐标高度约 `0.86m ~ 0.92m` 处不规则的手绘分界 |
| 宽木地板与桌面 | 暖棕 / 蜂蜜木 | `(0.16, 0.088, 0.042)` → `(0.48, 0.285, 0.138)` | 拼板独立倒角，承接火光的暖色反光 |
| 屋梁与门窗外框 | 深胡桃木 | `(0.07, 0.038, 0.018)` → `(0.24, 0.135, 0.065)` | 框定空间边界，压住画面四角 |
| 门板漆面 | 做旧橄榄绿 | `(0.08, 0.12, 0.055)` → `(0.25, 0.31, 0.14)` | 搭配深色横向木档与铁件 |
| 工作台与窗格 | 褪色灰蓝 / 青绿 | `(0.06, 0.11, 0.17)` → `(0.20, 0.30, 0.40)` | 和暖木色、火光形成冷暖平衡 |
| 剥落露砖 / 工具箱 | 暗陶红 | `(0.18, 0.055, 0.032)` → `(0.48, 0.18, 0.105)` | 小面积点缀 |
| 火焰与炭火 | 琥珀金 → 深橙红 | 核心 `(1.0, 0.80, 0.28)` / 外焰 `(0.85, 0.14, 0.015)` | 不能过曝成死白，保留橙金层次 |
| 窗外暗夜 | 极暗寒夜蓝黑 | `(0.012, 0.024, 0.048)` | 衬托室内温暖，强化"外面冰冷危险" |

规则：

- 新场景的主色调先从这张表里选，需要新增颜色时在本表里登记。
- 高饱和颜色只留给光源和极少数叙事物件。
- **双色墙**：用世界坐标高度加低频噪声驱动墙裙分界线，不让多块墙体出现错位接缝。
- **玻璃**：不用噪点重的抖动半透明，统一用平滑混合透明（Godot Alpha Blend）加轻微菲涅尔反射，既能映出火光，又能看清窗外的松林剪影。

## 4. 材质（已定）

- **基础色**：大块水粉、油画笔触，柔和色块过渡（同色系 2 到 3 档明暗），不要照片级的高频杂色。
- **缝隙压暗**：墙角、木梁交接、家具底部和木板缝隙叠加柔和的 AO 乘法压暗，系数 `0.35 ~ 0.45`。
- **粗糙度**：

| 材质 | Roughness |
| --- | --- |
| 抹灰墙、石材、木炭、织物、毛皮 | `0.85 ~ 0.96` |
| 做旧木材、木地板、木家具 | `0.72 ~ 0.85` |
| 做旧铁器、工具箱 | `0.55 ~ 0.68` |
| 搪瓷、旧黄铜、玻璃 | `0.08 ~ 0.45`，克制的高光，用来捕捉火光 |

- **凹凸**：只用低频柔和的笔触高度，强度 `0.05 ~ 0.18`，不出现刺眼的细沙噪点。

## 5. 光照

### 5.1 实体光源原则（已定）

- 室内**不启用任何通电照明**。天花板的旧搪瓷吊灯保持熄灭，作为文明衰退的环境叙事。
- 暗室的全部照明以**火堆**为唯一主光源：
  - **主火焰光**：暖橙 `(1.0, 0.46, 0.13)`，在火焰中心偏上，投射主要的动态阴影。
  - **低位炭火光**：深红橙 `(1.0, 0.20, 0.035)`，贴近炭床，勾勒石块、地板缝和柴火底面。
  - **火光反弹补光**：低功率、大半径、无阴影的暖色补光，模拟火光经过土墙和木顶的二次反弹，保证前景和角落轮廓可读，但不破坏火堆投影的方向。
  - **窗外**：只保留极弱的寒夜底色，在窗台外侧叠一点暖色外溢，呼应 `builder.light_spills`（"火光从窗口漏出去，落进外面的黑暗里"）。
  - **体积雾**：密度极低，只用来烘托火堆周围的暖晕，不能让画面发灰或出噪点。
- 其他场景沿用同一原则：先确定场景里有哪些实体光源，再布光。不允许为了"看清楚"加一盏没有来源的灯。

### 5.2 光照即信息闸门（已定）

火越旺照得越远。物体看不看得清取决于光能不能照到它。还没到揭示时机的东西放在光照不到的地方，或者在 Blender 里放进 `90_Later_Reveals` 集合，由表现层在合适的时候显现（见 `docs/modeling.md`）。

### 5.3 暗室的状态映射（已定）

表现层只订阅 `SimEvents` 的信号，不直接改模拟状态。

| 模拟状态 | 信号 | 画面 |
| --- | --- | --- |
| 火灭（`DEAD = 0`） | `fire_changed(0)` | 火焰和火光全灭，炭床发暗，只剩窗外微弱的寒夜轮廓 |
| 闷烧（`SMOLDERING = 1`） | `fire_changed(1)` | 只有炭床的暗红微光和低位炭火光，火焰隐藏，室内近乎漆黑 |
| 摇曳（`FLICKERING = 2`） | `fire_changed(2)` | 小火苗晃动，主火光低强度不稳定闪烁，火光开始漏出窗口 |
| 燃烧（`BURNING = 3`） | `fire_changed(3)` | 正常火焰、少量上升的火星，稳定照亮门、角落和前景 |
| 熊熊燃烧（`ROARING = 4`） | `fire_changed(4)` | 最大火焰、活跃火星、最暖最大的照明半径，照亮右侧的工作台和货架 |
| 建造者状态（`-1 ~ 4`） | `builder_changed` | 陌生人来了以后角落出现铺位和斗篷；她愿意帮忙以后，围裙、工具和待造的东西逐步出现 |
| 库存与建造 | `store_changed` / `building_changed` | 柴堆随木头库存增减；货架上的毛皮、布料、罐子随库存出现 |

### 5.4 引导用的光（已定）

建造者去砍柴时门外发光，吸引玩家去点门。这道光必须是世界里的光（门缝里漏进来的天光），**不能**是脉动的描边、高亮或图标。这种引导整个游戏里尽量少用，用多了就是换了皮的感叹号。

## 6. 2D 人物

### 6.1 形式（已定）

人物是**厚涂手绘的 2D 立绘**，做成纸片放进 3D 场景：用受光的哑光材质，不用自发光，让火光真实地扫过人物并投下轮廓阴影。参考气质：《邪恶冥刻》《暗黑地牢》的绘本、舞台剧感。

### 6.2 建造者（已定，参考 `Art/characters/builder_2d_standee.png`）

- 二十多岁到三十出头的女性，风霜、疲惫，眼神克制而警觉，话很少。
- 破损的橄榄褐连帽披肩，兜帽和碎发半遮眉眼，保留神秘感。
- 做旧灰蓝帆布工装围裙和皮革工具带，挂着木槌、麻绳、生锈的铁钳。颜色呼应暗室的墙裙和工作台。
- 手里拿着一根劈柴，呼应"她往火里添了一根柴"。
- 需要的状态立绘：倒在角落发抖（`builder_changed` 的早期状态）、站在火边、干活。现在只有站立的一张。

### 6.3 人物立绘规则（建议）

- 剪影清楚，在暗处只看轮廓也能认出是谁。
- 面部不画细节表情，或者被兜帽、阴影遮住一部分。人物的情绪由姿态和光来表达。
- 用色从第 3 节的色表里取，和所在的场景同一套冷暖关系。
- 透明边缘不能有白边，放在暗背景上检查。
- 同一个人物的不同状态立绘，比例、光向、笔触必须一致。

## 7. 势力风格

制作人的方案是参考《赛博朋克 2077》的四种时代风格（实用主义、刻奇、新军阀、新刻奇），给四个群体各定一套视觉风格：

| 群体 | 对应的风格 | 状态 |
| --- | --- | --- |
| 流浪者（仆从地位） | 实用主义 | 已定方向，形状语言和材质待定 |
| 流浪者（市民地位） | 刻奇 | 已定方向，细节待定 |
| 野生动物 | 新军阀 | 待定。建议改为覆盖在其他风格上的一层有机侵蚀，而不是独立的一套 |
| 流浪者（舰队） | 新刻奇 | 已定方向，细节待定 |

规则：

- **先只做一套**，验证副本拼装出来好不好看、重复感强不强，再做第二套。先做哪一套待定。
- **舰队风格不能在一周目早期清楚地出现**，否则会提前泄露"玩家就是主导地位的流浪者"。玩家后来用外星合金拼的飞机，风格要逐步向舰队风格靠拢，而不是一开始就一样。风格本身也是线索，算进线索预算（见 `docs/narrative.md`）。
- 每套风格定稿时，在本节补上：形状语言（剪影、比例、重复的几何元素）、主材质、主色、标志性的道具。

## 8. UI 与字体

### 8.1 UI（已定）

- **正式画面尽可能不出现文字**（见 `docs/narrative.md` 第 4 节）。没有文字日志、按钮文字、物品名称、数值。数值和叙述文字只在调试台里看。
- 禁止：脉动描边、感叹号或红点、进度条、飘字、数字滚动、闪烁的"新"标记、成就弹窗。
- UI 放进世界里：柴堆的根数就是木头的库存，门外的光就是"现在可以出去"，货架上的东西就是你有什么。
- 抽象图标也尽量不用。能用世界里的物件表达的，不画成图标。
- 画面要能独立讲清楚发生了什么。审核截图时把它当成一部默片来看。
- 系统菜单（设置、存档、退出）可以有文字，用同一个 `Theme`，克制、低对比。

### 8.2 字体（待定）

- logo（`Art/common/logo/Eng.png`）的设计语言是纯黑底、单一骨白色、粗衬线打字机体。标题、系统菜单和制作人员名单的字体朝这个方向选。
- 中文字体和中文 logo 待定。候选必须允许商用和随开源项目分发（例如 SIL OFL 授权的字体），选定后在这里写明字体名、授权和字号。

## 9. 特效与后处理

### 9.1 特效（已定）

- 火焰和火星用风格化着色器和粒子（`presentation/room/shaders/`），跟随火势变化。
- 特效服从"光即信息"：不为好看加没有来源的光效、拖尾、屏幕震动。

### 9.2 后处理（已定）

- Godot 的 `WorldEnvironment` 用 `AgX` 色调映射，对应 Blender 预览的 `AgX`（Medium High Contrast）。
- `Glow` 很轻，只作用于火焰和火星这类高亮的发光体。
- 体积雾可选，强度很低。
- 所有舞台共用同一份环境配置（放在 `presentation/common/`），2D 立绘和 3D 场景经过同一套后处理。

## 10. 审核流程

1. AI 产出：Blender 渲染图或 Godot 运行截图，固定机位，至少一张全景、一张近景。暗室这类有火势变化的场景，至少截"火灭"和"燃烧"两档。
2. 和 `Art/scenes/*_preview.png` 这类已确认的参考图并排对比，在交付说明里写出差异。
3. 制作人确认后，素材才算完成。没确认的素材可以进游戏，但要在交付说明里标"待审"。
4. AI 生成的图片可以用作概念参考和立绘底稿。进正式版的素材要经过制作人确认，并在素材清单里注明来源。
